# シール帳アプリ
https://topaz.dev/projects/35fd5adcb9908933432a
# ターゲット
主に小学生
- 休み時間に友達とシール交換をしたい
- 友達を作りたい
- シールが好き、集めたい
# 機能
- ユーザー名登録
- シールを入手する方法
    - ログインボーナス
        - ボタンを押すと1日1枚ランダムにシールがもらえる
  
- 「交換」機能： 
    - 送信
        - 友達を選択する→交換したいシールを選択する→友達にリクエストがおくられる
   - 受信
        - 友達からリクエストが来る→交換するシールを選択→送られたシールを受け取る→デバイスに保存
- 「シール帳」機能：
    - 自分が持っているシールを見える化する機能
    - シールを選択すると大きく表示される
# 役割分担
